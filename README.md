# Dorvan Burger

Cardápio digital de uma hamburgueria fictícia, desenvolvido como projeto de portfólio para demonstrar uma experiência de compra simples, intuitiva e responsiva.

<p align="center">
  <a href="https://ericagomes-dev.github.io/dorvan-burger/"><strong>🍔 Acessar demonstração online</strong></a>
</p>

> **Demonstração:** o carrinho e o checkout são simulados. Não são enviados pedidos reais e nenhum pagamento é processado.

## Funcionalidades

- Cardápio organizado por categorias.
- Personalização de ingredientes e adicionais.
- Carrinho com edição de itens e cálculo do total.
- Checkout demonstrativo.
- Layout adaptado para computadores e celulares.

## Tecnologias

- React
- TypeScript
- Vite
- SCSS

O backend em Node.js e PostgreSQL permanece no repositório como base para uma futura versão completa.
